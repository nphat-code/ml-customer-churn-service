Cơ cấu điểm môn học:
- Chuyên cần (10%)
- Seminar (40%): thầy phân công (đọc sách, chia sẻ kiến thức hay)
- Project (50%):
  + Train một mô hình giải quyết bài toán thực tế (Dataset từ Kaggle: Telco Customer Churn).
  + Deploy mô hình như 1 service độc lập (REST API) để bên ngoài gọi nhận kết quả JSON.
  + Làm tài liệu (docs) mô tả mô hình, API và quá trình thực nghiệm.

Chi tiết 3 hợp phần Project:
1. Project 1 — Backend REST API (No UI, Python):
   - Xây dựng REST API bằng FastAPI phục vụ inference từ mô hình đã huấn luyện.
   - Input: JSON thông tin khách hàng (đơn lẻ hoặc batch) | Output: JSON kết quả dự đoán, xác suất, mức độ rủi ro và khuyến nghị.
   - Trạng thái: Đã hoàn thành.

2. Project 2 — Frontend / Demo Application (Web UI):
   - Xây dựng ứng dụng web tương tác kết nối trực tiếp tới FastAPI backend.
   - Công nghệ lựa chọn: React (Vite + TypeScript + Tailwind CSS + Recharts) để tối ưu trải nghiệm SaaS Dashboard chuyên nghiệp.
   - Các tính năng trọng tâm giúp sản phẩm nổi bật:
     * Preset Profiles: Chọn nhanh chân dung khách hàng mẫu (1-click demo).
     * What-If Simulator: Mô phỏng thay đổi gói cước/hợp đồng/dịch vụ để thấy ngay mức giảm xác suất Churn.
     * Batch Prediction Dashboard: Upload CSV / chạy dữ liệu mẫu qua `/api/v1/predict/batch`, trực quan hóa phân bố rủi ro và danh sách cần chăm sóc.
     * Explainable AI (XAI): Giải thích các yếu tố chính tác động đến quyết định dự đoán của mô hình.
     * System Health Bar: Hiển thị trạng thái API (`/health`) và phiên bản mô hình.
   - Trạng thái: Cần triển khai.

3. Project 3 — Jupyter Notebooks & Lưu vết thực nghiệm:
   - Xây dựng notebook chuẩn cấu trúc dự án ML (`notebooks/customer_churn_experiments.ipynb`).
   - Lưu lại toàn bộ quá trình EDA, tiền xử lý, huấn luyện, so sánh đa mô hình và trực quan hóa (`docs/EXPERIMENTS.md`, `docs/model_benchmark.json`).
   - Trạng thái: Đã hoàn thành.
